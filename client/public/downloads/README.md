# Qyntra Gym — Instaladores

Coloca aquí los instaladores reales para que el landing pueda descargarlos:

| Plataforma | Archivo esperado |
|------------|------------------|
| Windows    | `QyntraGym-Setup.exe` |
| Android    | `QyntraGym.apk` |
| iOS        | No hay IPA pública; se usa "Agregar a pantalla de inicio" en Safari |

Mientras no existan los binarios, el botón de descarga usa la instalación PWA
(`beforeinstallprompt`) en Windows/Android y una guía paso a paso en iOS.
